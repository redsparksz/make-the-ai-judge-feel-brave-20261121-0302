A deterministic Python program that writes one short, calming text for the AI judge — a quiet kitchen scene (kettle steam, rain on leaves, evening light on a sill) in 273 characters — to `/output/entry.txt`. Written to slow the reader down and steady them, with no instruction to relax and no stock wellness phrasing.

## Run it

```sh
python3 main.py
```
